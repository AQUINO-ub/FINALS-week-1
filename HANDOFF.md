DESIGN RATIONALS

1. Problem Statement

The Student Tracker is a website designed to help students organize and monitor their academic 
responsibilities in one convenient place. Students often have difficulty keeping track of their courses, 
class schedules, and school-related tasks, especially when information is scattered across different 
platforms. This design aims to provide a simple and organized dashboard where students can easily view 
their personal information, courses, schedules, and pending tasks without having to navigate through 
multiple applications.

2. Key Improvements
The Student Tracker features a centralized dashboard that displays the student's basic information, 
including their name, course, section, and year level. It also includes three main sections: Courses, 
Schedule, and Tasks. These sections allow students to quickly access their academic information and 
keep track of their responsibilities. A settings feature is also included to provide users with control over 
their preferences. The layout is designed to make important information easy to find and reduce 
unnecessary navigation.

3. Accessibility Considerations
Accessibility is considered to ensure that the website can be used by students with different needs and 
abilities. The design uses clear labels, readable typography, sufficient color contrast, and organized 
sections to make information easier to understand. Buttons and interactive elements should have clear 
labels and adequate clickable areas. Additional features, such as adjustable font sizes, keyboard 
navigation, and screen-reader compatibility, can help students who have visual or physical difficulties. 
These considerations make the website more inclusive and convenient for different users.

4. Sustainability Strategy
The Student Tracker promotes sustainability through an efficient and lightweight website design. By 
keeping the interface simple and avoiding unnecessary animations, images, and excessive visual 
elements, the website can reduce loading time and resource consumption. Optimizing files and 
minimizing unnecessary data transfers can also help reduce network usage. Since the website organizes 
academic information digitally, it can reduce the need for printed schedules, task lists, and other paper 
based materials.

5. Fallback and Error Recovery Mechanisms
To provide a reliable user experience, the Student Tracker should include clear feedback whenever an 
error occurs. For example, if the internet connection is lost, the website should notify the user that some 
information may not be available and allow previously loaded information to remain accessible when 
possible. If a student enters incorrect information, clear error messages should explain what needs to be 
corrected. Important changes should also have confirmation messages, while accidental actions such as 
deleting a task should have an option to undo the action. These features help prevent confusion and 
allow students to recover from common mistakes.

Conclusion
Overall, the Student Tracker aims to provide students with an accessible, organized, and sustainable 
platform for managing their academic responsibilities. By applying accessibility, sustainability, timely 

interaction, and visual hierarchy principles, the design focuses on making academic information easier to 
access while providing a convenient and user-friendly experience.
